# Sonic Adventure MVP

Um fan game de navegador reconstruído como um protótipo jogável de plataforma/runner, usando **Phaser 3 + Arcade Physics** e arte vetorial original gerada no próprio código.

## O que mudou

- Sonic estilizado em vetor, com espinhos, luvas, tênis e animação de movimento.
- Corrida com aceleração e impulso.
- Pulo e rolamento.
- Anéis, inimigos e obstáculos.
- Bola de energia arremessável.
- Pipa: reduz a gravidade e permite planar.
- 3 fases com progressão: **Green Hill → Sky Ruins → Neon City**.
- HUD com fase, anéis, pontuação e vidas.
- Tela inicial e tela de vitória.
- Controles de teclado e botões touch para celular.
- Sem assets proprietários do jogo original: o personagem e elementos visuais são desenhados em código.

## Controles

**PC:** ← → correr · SPACE/W pular · SHIFT rolar · Q jogar bola · E soltar pipa · R reiniciar.

**Celular:** use os botões na tela para correr, pular e lançar a bola.

## Tecnologia

O protótipo usa Phaser 3.90 e Arcade Physics, adequado para jogos 2D de plataforma/arcade. A entrada de teclado e toque é tratada pelo sistema unificado de input do Phaser.

## Publicação

O projeto continua compatível com GitHub Pages. O carregamento do Phaser usa CDN, portanto o jogo precisa de conexão com a internet quando executado pela página publicada.

## Escopo

Projeto educacional/fan game independente; não é um produto oficial da SEGA e não utiliza os assets oficiais.
